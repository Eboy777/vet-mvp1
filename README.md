# Breach AI

Рабочий учебный прототип для начинающих ветеринарных специалистов. Интерфейс основан на предоставленных примерах: карта пациента, диалог, вкладки заметок, обследований и тренера.

## Что работает

- Один вымышленный клинический кейс: кот Марс с нарушением мочеиспускания.
- Виртуальный владелец на gpt-6.1-sol через https://api.aijuju.rest/v1/chat/completions.
- Свободный диалог и подсказки вопросов, автоматическое выделение фактов анамнеза.
- Осмотр, биохимия и электролиты, ЭКГ, УЗИ, общий анализ крови с результатами.
- Дифференциальные диагнозы, выбор диагноза и обоснование.
- План лечения, первое действие, объяснение владельцу.
- Чек-лист на 100 баллов, разбор пропусков и опасных назначений, индивидуальный комментарий ИИ.
- Сохранение прохождения в текущем браузере и сброс с подтверждением.
- Мобильная версия с переключением между пациентом, диалогом и инструментами.

## Локальный запуск

Нужен Node.js 22.13+.

1. Распаковать проект и открыть его папку в терминале.
2. Выполнить `npm ci`.
3. Создать файл `.dev.vars` на основе `.env.example` и вписать свой ключ в `BREACH_API_KEY`.
4. Выполнить `npm run dev` и открыть адрес, указанный в терминале.

Ключ не включён в архив. Он используется только на сервере. ИИ-запросы передают текст учебного диалога указанному API-провайдеру. Локальный транспорт поддерживает стандартный HTTPS_PROXY, если он задан средой.

## Проверки

`npx tsc --noEmit` — типы.
`npm run build` — сборка приложения.

Основной сценарий проверяется в браузере: анамнез → обследования → дифференциалы → диагноз → лечение → разбор.

## Клинические ограничения

Материал предназначен для обучения и не заменяет клинические протоколы. Данные и цены условные. Дозировки не моделируются. ИИ-комментарий может ошибаться; воспроизводимые результаты обследований и базовый чек-лист задаются сценарием. Баллы за обоснование и коммуникацию учитывают наличие ответа минимальной длины; качество содержания разбирает ИИ отдельно.

Основа сценария:
- iCatCare consensus guidelines 2025: https://doi.org/10.1177/1098612X241309176
- MSD Veterinary Manual: https://www.msdvetmanual.com/urinary-system/urolithiasis-in-small-animals/urethral-obstruction-in-small-animals

## Развёртывание

Рабочая версия: https://breach-ai.ka317090.workers.dev

Приложение размещено в Cloudflare Workers. Ключ хранится в серверном секрете `BREACH_API_KEY`.

После `npm run build` выполните `npx wrangler deploy --config dist/server/wrangler.json --name breach-ai`. Затем установите ключ командой `npx wrangler secret put BREACH_API_KEY --config dist/server/wrangler.json --name breach-ai`.

## Архитектура

React 19 и TypeScript, маршрутизация App Router, сборка vinext/Vite и Cloudflare Workers. Интерфейс использует CSS и компоненты на Tailwind CSS/Radix UI. Прогресс хранится в localStorage. Клинический сценарий и проверка решений находятся в `lib/case.ts`; серверный `/api/chat` вызывает внешний OpenAI-совместимый API для диалога и персонального разбора. База данных и пользовательские аккаунты в текущем MVP не используются.
